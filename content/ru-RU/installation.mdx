# Установка

Краткое руководство по запуску сервера Lumi

## Установка Java

Сначала убедитесь, что у вас установлена Java 21, необходимая для запуска сервера. Откройте терминал и выполните команду:

```bash
java --version
```

Если Java не установлена или установлена другая версия, рекомендуем скачать [Azul Zulu JDK](https://www.azul.com/downloads/?version=java-21-lts&package=jdk#zulu)

## Ручная установка

Перейдите на [страницу загрузки Lumi](https://dl.lumi.su/?branches=stable) или скачайте последнюю версию по [этой ссылке](https://dl.lumi.su/download/stable/latest)

### Запуск:

<Steps>
### Шаг 1

После загрузки поместите файл в любую выбранную папку.

### Шаг 2

Откройте терминал и перейдите в папку, содержащую загруженный JAR-файл:

```bash
cd path/to/your/jar
```

### Шаг 3

Запустите сервер с помощью следующего шаблона команды:

```bash
java -jar Lumi-<version>.jar
```

замените `<version>` на соответствующую версию, например полная команда:

```bash
java -jar Lumi-1.6.4.jar
```

</Steps>
